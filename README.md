# lialog_privacy-policy

**Deutsch (DE)**
Diese App speichert alle Einträge zu Ihrem Baby oder Kind, wie Schlafzeiten, Mahlzeiten, Windeln, Wachstum, Medikamente, Gesundheitseinträge, Notizen, Erinnerungen und Sicherungen ausschließlich lokal auf Ihrem Gerät. Es findet kein automatischer Versand an den Entwickler oder an Dritte statt.

Zugriff wird nur auf Funktionen benötigt, die Sie aktiv nutzen: Benachrichtigungen für Erinnerungen, Speicherzugriff für Backups und Wiederherstellung sowie Netzwerkzugriff für die Play Store-Lizenzprüfung und In-App-Käufe.

Eine Weitergabe personenbezogener Daten erfolgt nur, wenn Sie freiwillig Kontakt per E-Mail aufnehmen, zum Beispiel über [contact@nuribit.eu](mailto:contact@nuribit.eu). Backups verbleiben in Ihrem Besitz; das Speichern oder Hochladen in eigene Cloud-Dienste liegt in Ihrer Verantwortung.
